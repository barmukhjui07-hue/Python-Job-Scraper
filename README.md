~~ Simple Python Job Scraper:

A lightweight Command Line Interface (CLI) application built in Python 3.11 that fetches live job listings from web pages and extracts clean job titles using basic string operations and `urllib`.

~~🌟 Features:
Uses Python's built-in `urllib.request` module (no external libraries required).
Line-by-line HTML parsing using simple string filtering and `.replace()`.
Extracts top live job listings directly into the terminal output.

~~🛠️ Concepts Used:
*Modules:* `urllib.request`
*Control Flow:* `for` loop, `if` statements, `break`
*Data Manipulation:* String decoding (`utf-8`), `.replace()`, `.strip()`

~~🚀 How to Run:
1. Open **Python IDLE 3.11**.
2. Open `job_scraper.py` in the IDLE editor.
3. Press **F5** (or click **Run -> Run Module**).
